# Oral-History.Digital

[![Ruby on Rails CI](https://github.com/oral-history-digital/ohd/actions/workflows/rubyonrails.yml/badge.svg?branch=main)](https://github.com/oral-history-digital/ohd/actions/workflows/rubyonrails.yml?query=branch%3Amain)
[![Frontend CI](https://github.com/oral-history-digital/ohd/actions/workflows/jest.yml/badge.svg?branch=main)](https://github.com/oral-history-digital/ohd/actions/workflows/jest.yml?query=branch%3Amain)

Oral-History.Digital is an open-source curation and research platform for
scholarly collections of audiovisual narrative interviews. It makes interviews
discoverable and usable as research data while supporting rights-aware access
and the privacy of interviewees.

Learn more at [oral-history.digital](https://www.oral-history.digital/en/projekt/index.html).

For development, concepts, guides, and operations documentation, see the
[documentation](doc/README.md).

At the moment, you can set up the OHD software in your development environment.
Without any modifications, it is probably not yet suitable for running in
production without any modifications. We are working on that.
